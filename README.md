# Portafolio de Electrónica y Sistemas Embebidos - Ing. Electrónico Eric Rodríguez Vásquez

¡Hola! Soy Eric, Ingeniero Electrónico especializado en desarrollo de sistemas embebidos y programación de microcontroladores. 
Este repositorio centraliza mis proyectos de hardware, firmware, simulaciones y artículos técnicos.

## 📂 Estructura del Repositorio

- **`01_proyectos/`**: Diseño de hardware, firmware y documentación de proyectos completos.
  - `01_fuente_lineal_lm317`: Fuente de poder analógica regulable (En progreso).
  - `02_proximo_proyecto`: [Título y estado del proyecto]
- **`02_articulos_tutoriales/`**: Guías técnicas, notas de aplicación y resolución de problemas.
- **`recursos/`**: Librerías de KiCad, footprints personalizados y scripts de utilidad.

## 🛠️ Stack Tecnológico

- **Hardware:** STM32, ESP32, AVR, PIC, ARM Cortex-M.
- **Software/Firmware:** C/C++, HAL/LL, ESP-IDF, FreeRTOS, PlatformIO, STM32CubeIDE.
- **EDA & Simulación:** KiCad, LTspice.
- **Herramientas:** Osciloscopio, analizador lógico, SWD/JTAG, GDB.
